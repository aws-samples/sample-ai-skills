# Tutorial

A guided lesson for people who have not used these skills before. A tutorial's
job is to give you a first success, so it makes every choice on your behalf and
follows one path from start to finish — no options, no branches, nothing to
decide.

No tutorial has been written for either skill domain yet. Until one exists, each
skill's page under [Skills](../skills/) records how it is invoked and what it
declares. Once you have been through a tutorial, [How-to](../how-to/) is where
you bring your own goal.
