# `software-docs`

Skills for a project's software documentation tree and the site that builds it. Two ship; each is
invoked only by its slash command.

| Skill | What it does |
|---|---|
| [`ai-doc`](./ai-doc/) | files each documentation page into the one Diátaxis mode and the one place it belongs: stands a tree up on first run, adopts flat pages one confirmed move at a time, assesses a page, surveys the tree, or writes a new page, reading which from the input rather than from a subcommand |
| [`ai-scaffold-docusaurus-site`](./ai-scaffold-docusaurus-site/) | scaffolds a Docusaurus 3 site around a project's docs tree, after a short interview on layout, audiences, and title, then builds it and counts its pages; it writes no content page |
