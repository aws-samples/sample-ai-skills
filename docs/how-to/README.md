# How-to Guides

Task-oriented directions for people who already know what they want to
accomplish. Each guide assumes you have a goal in mind and shows the shortest
reliable route to it — no scenario is invented for you, and nothing here teaches
the system from scratch.

- [Install Skills with the Installer](install-skills-with-the-installer.md) — install
  skills for one or more coding agents, screen by screen

For what a single skill is and how it is invoked, see [Skills](../skills/).
