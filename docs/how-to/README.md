# How-to Guides

Task-oriented directions for people who already know what they want to
accomplish. Each guide assumes you have a goal in mind and shows the shortest
reliable route to it — no scenario is invented for you, and nothing here teaches
the system from scratch. If you have never used these skills before, start with
the [tutorial](../tutorial/) instead.

No how-to page is published yet. The guides that exist today are about operating
this repository rather than about using a skill, so they are maintainer-facing and
not part of this tree. For what a single skill is and how it is invoked, see
[Skills](../skills/).
